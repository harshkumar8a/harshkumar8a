### 🧠 Featured GenAI / Agentic AI Projects

**🛡️ Guardrailed Customer Support Assistant**
An enterprise-grade conversational AI assistant built with **NVIDIA NeMo Guardrails**, layered on top of an agentic architecture to keep interactions safe, on-topic, and policy-compliant. Implements topical rails, input/output moderation, and jailbreak/hallucination mitigation while preserving natural, helpful conversation flow for real customer support workflows.

**🧭 Margsafar — Multi-Agent Travel Intelligence Assistant**
An agentic AI travel planning system ("Marg" = path, "Safar" = journey) powered by multiple coordinated agents, each responsible for a distinct task — search, itinerary planning, and recommendations. Uses the **Tavily** search API as a real-time information retrieval tool so agents can ground responses in live web data, orchestrated through a multi-agent, tool-calling architecture for accurate, up-to-date travel guidance.
